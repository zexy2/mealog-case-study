`foods.jsonl` contains 57 selected rows whose nutrient values identify TürKomp
as their source. The following are mealog metadata, not official TürKomp fields:

- `food_id`
- transliterated or display labels
- aliases and negative aliases
- serving defaults and density annotations
- retrieval, portion, and confidence behavior
