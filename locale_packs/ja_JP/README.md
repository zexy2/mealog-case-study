# Japanese locale-pack data notice

Source: [MEXT, Standard Tables of Food Composition in Japan](https://www.mext.go.jp/a_menu/syokuhinseibun/index.htm).

MEXT states that food-composition data may be reused and asks secondary users
to identify the relevant Standard Tables as the source. This pack remains
`unverified`: mealog has not established the exact source edition for every
selected row or completed a commercial-publication review. Commercial mode
therefore rejects it.

Project `food_id` values, English display labels, aliases, serving defaults,
density annotations, retrieval metadata, and confidence behavior are mealog
metadata, not official MEXT fields. See the repository-level
[third-party data notice](../../THIRD_PARTY_DATA.md) for the full boundary.
